# Programação Orientada a Objetos
É um paradigma de programação que oferece uma maneira de organizar e estruturar o código de forma mais intuitiva e eficiente, modelando o mundo real em software

## Tipos abstratos de dados
### Classes
Um modelo ou um molde que define **propriedades** e [métodos](Método) para os [objetos](Objeto) pertencentes a essa classe. Uma forma de mostrar essas classes é através do **diagrama de classes** de um [[UML]]. Algumas das principais características das classes são:
- **Define um tipo**: serve somo modelo para criar novos tipos de dados personalizados
- **Determina características**: Especifica as propriedades que os objetos desse tipo terão.
- **Define comportamentos**: define os métodoss que os objetos desse tipo podem executar
- **Gera objetos**: a partir de uma classe, podemos criar inúmeros objetos, cada um com seus próprios dados únicos
