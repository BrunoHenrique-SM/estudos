# Docker
- O que é um docker?
	É uma ferramenta que separa o computador em partições([container](Container)), para rodar servidores de forma independente, pois, perceberam que algumas vezes utilizar uma VM gerava um consumo extra desnecessário para uma aplicação simples, então o docker apareceu como um opção mais eficiente
- Como fazer uma [Máquina virtual(VM)](Virtual Machining)?

## Como funciona o Docker
O funcionamento do docker pode ser dividido em 3 partes **build**, **ship** e **run**
